# Script to Screen

Static [Reveal.js](https://revealjs.com/) deck: **The Science of Why Content Works** (UT Austin).

## View locally

Open `script_to_screen.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/script_to_screen.html`.

## GitHub Pages

With Pages enabled (**Settings → Pages → Branch `main`, folder `/ (root)`**), the site is served from the repo root; `index.html` redirects to the main deck.
